Duplicate one of these files in `_projects/`, update the front matter, and replace the body with your project description.

Useful fields:

- `title`: project title
- `description`: short card description
- `img`: optional image path, for example `assets/img/YOUR-PROJECT-IMAGE.jpg`
- `importance`: lower numbers appear first
- `category`: one of the categories listed in `_pages/projects.md`
